# wanoful.com

Personal academic homepage of **Zhaoyuan Wan (万钊源)**, undergraduate student in the **ACM Honors Class**, **Zhiyuan College, Shanghai Jiao Tong University (SJTU)**.

- **Website**: [https://wanoful.com](https://wanoful.com)
- **Stack**: TypeScript + Vite

## Development

```bash
# Install dependencies
pnpm install

# Start local dev server
pnpm dev

# Build production static bundle into dist/
pnpm build
```
